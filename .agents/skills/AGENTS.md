# Shared Skills File Map

This directory contains repository-shared agent skills.

- Create new repository-specific skills in this directory rather than in `~/.codex/skills`.
- `agents-rule-curator/` - skill for distilling conversation decisions into user-selected `AGENTS.md` rules. See `agents-rule-curator/AGENTS.md`.
- `map-agents-files/` - skill for creating or updating `AGENTS.md` file maps across a repository. See `map-agents-files/AGENTS.md`.
