# MCP Package Map

This package contains the K-commerce MCP server entry point and package metadata.

## Directories

- `src/` - Python source tree for the package. See `src/AGENTS.md`.

## Files

- `README.md` - package-level overview for the MCP server.
- `pyproject.toml` - package metadata, build backend, and `k-commerce-mcp` console script definition.
- `src/k_commerce_mcp/__init__.py` - package marker for the MCP server module.
- `src/k_commerce_mcp/server.py` - console script entry point; currently prints a placeholder message until the MCP server is implemented.
