# CLI Package File Map

This package provides the `k-commerce` command-line application and provider automation.

## Package files

- `pyproject.toml` - CLI package metadata, dependencies, and console script entry point.
- `README.md` - CLI-specific usage documentation.

- `src/` - importable CLI source tree. See `packages/cli/src/AGENTS.md`.
- `tests/` - unit, integration-style, e2e, and smoke tests for CLI behavior. See `packages/cli/tests/AGENTS.md`.
